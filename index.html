Ubicación en formularios Kobo

Compatible con Firefox, Chrome, Edge, Samsung Internet y navegadores de iPhone/iPad. El permiso de ubicación lo administra cada navegador para ee.kobotoolbox.org; si usa más de uno, debe autorizar Kobo en cada navegador.

Configurar ubicación para Kobo

El portal no está amarrado a un navegador específico. La ubicación la solicita el formulario de ee.kobotoolbox.org y cada navegador conserva sus propios permisos.

Android — Firefox, Chrome, Edge, Samsung Internet u otro navegador

  1. Mantenga activa la ubicación del teléfono.
  2. En los permisos de Android para el navegador que esté usando, habilite Ubicación mientras se usa la aplicación y, si aparece, Ubicación precisa.
  3. Abra un formulario Kobo y autorice el acceso a la ubicación. Si el navegador ofrece una opción para recordar o mantener la decisión, actívela.
  4. En Firefox, si aparece “Recordar esta decisión”, márquela para evitar que el permiso quede únicamente temporal.

iPhone / iPad

  1. Active Servicios de localización en iOS.
  2. Conceda ubicación al navegador que utilice (Safari, Firefox, Chrome u otro) mientras la app esté en uso.
  3. Al abrir Kobo, permita también la ubicación para el sitio. En Safari puede revisar el permiso del sitio desde la configuración de Safari o la configuración del sitio web.
Importante: una página web no puede forzar un permiso de ubicación “para siempre”. La duración depende del navegador y del sistema operativo. Además, los permisos no se comparten entre Firefox, Chrome, Safari u otros navegadores; si una persona cambia de navegador, debe autorizar Kobo en ese navegador también.

Instalar el Portal Bocadeli

Abra el menú de su navegador y busque una opción como “Instalar”, “Añadir a pantalla de inicio” o “Agregar a pantalla de inicio”. El nombre puede variar según el navegador y el teléfono.

Nota: el portal puede usarse sin instalarlo. La instalación solo facilita el acceso desde el icono de la pantalla de inicio.
